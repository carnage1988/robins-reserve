# Discord Preorder Bot

A Discord bot that automates preorder management for a local trading card game store.

## Features

- Discord DM preorder requests
- Configurable trigger phrases
- Google Sheets integration
- Staff approval using 👍 reactions
- Automatic stock deduction
- Customer purchase limits
- Unique pickup PIN generation
- Customer confirmation messages
- Staff approval notifications

## Technologies

- Python 3
- discord.py
- Google Sheets API (gspread)
- Git

## Current Version

v0.1.0
